# Uber-Analysis

## Overview
This project analyzes Uber ride data using Python to identify patterns related to ride purpose, category, time, and distance.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- VS Code

## Key Insights
- Majority of rides are booked for business purposes
- Most rides occur during afternoon hours
- Most trips are short-distance 
- Fridays have the highest ride frequency

## Conclusion
This project demonstrates data cleaning, feature engineering, visualization, and insight generation using real-world Uber data.
